How to use

Tools

V select · B box · A arrow · T text · G group frame

Draw by dragging. With a shape selected, just type to label it — Enter commits, Shift+Enter adds a line, Esc cancels.

Shape styles — Cmd/Ctrl+D

Cycles the kind-appropriate variant of everything selected:

  • Box: square ⇄ rounded ╭─╮
  • Arrow: solid ⇄ dashed ─ ─ / ┊
  • Group: plain frame → 2 → 3 → 4 → 5 swimlanes → plain

Swimlanes

  • Cmd/Ctrl+D on a group frame adds lanes; keep pressing to add more.
  • Double-click a lane header to rename it; the group's own title lives in the tab.
  • Moving the frame carries everything inside; resizing keeps each item in its lane.

Arrows

Cmd/Ctrl+B or right-click cycles heads (end → both → start). Right-click a box, then right-click another box to connect them — or right-click empty canvas to create a new connected box there (also works with a box selected). Drag from a selected box's border to start an attached arrow.

Everything else

E copy diagram as text · Shift+E preview/download · paste a text diagram to import it · Cmd/Ctrl+C copy selection · L auto-layout · Shift+L tidy · Cmd/Ctrl+Z undo
